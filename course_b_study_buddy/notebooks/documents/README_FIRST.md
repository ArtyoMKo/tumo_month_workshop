# About these sample documents

These four files describe **the Kestrel Project** — a high-altitude balloon programme that
does not exist. It was invented for this workshop.

That is the entire point. Because no AI model has ever seen these documents, it *cannot*
know anything in them. So when you ask a question about Kestrel:

- **without** giving the model the documents, any answer it gives is invented — and you can
  prove it, because you can check against the real text
- **with** the documents retrieved and supplied, a correct answer can only have come from
  the retrieval working

Real notes can't give you that. If you asked about photosynthesis, the model would know the
answer anyway and you'd never be able to tell whether your retrieval was doing anything.

**From Lesson 7, replace these with your own material** — but keep them around. They're
useful for checking whether a change you made broke something.
